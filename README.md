CoreCRM – Frontend

A modern, responsive CRM application built with React and Vite, designed to manage leads, companies and business opportunities.

---

Technologies


React

Vite

React Router

Lucide React

Recharts

JavaScript

CSS

---

Features


Dashboard with business statistics

Lead management

Company management

Lead search and filtering

Create, edit and delete records

REST API integration

Responsive user interface

Progressive Web App (PWA) support

Requirements

Before installing the application, make sure you have:

Node.js
npm
Git

---
CoreCRM Backend API running
---

Installation
1. Clone the repository
   

git clone

 https://github.com/antoniopamantec/challengyAgriVenture.git

3. Navigate to the Frontend folder
   

cd challengyAgriVenture/frontend

5. Install dependencies
   

npm install



5. Start the development server
   

npm run dev

6. Access the application

Open your browser and navigate to:

text
http://localhost:5173
